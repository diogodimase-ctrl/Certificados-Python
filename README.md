# Certificados · Pós-graduação

Programa que gera os certificados dos docentes da pós-graduação e manda para o
fluxo do Power Automate enviar por e-mail.

## Instalar ou atualizar

1. Clique no botão verde **Code** → **Download ZIP** (ou baixe só o arquivo
   `Instalar-Certificados-<versão>.exe` desta página).
2. Abra o `Instalar-Certificados-<versão>.exe`.
   Se o Windows mostrar "O Windows protegeu o computador", clique em
   **Mais informações → Executar assim mesmo**.
3. Avance até o fim (não pede senha de administrador). Abra pelo atalho
   **Certificados** na Área de Trabalho.

O programa avisa sozinho, no alto da janela, quando sai uma versão nova.

## Pastas

- `Instalar-Certificados-<versão>.exe` — o instalador da versão atual.
- `codigo/` — o código do programa (não precisa dele para usar).
